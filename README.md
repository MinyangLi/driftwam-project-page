# DriftWAM project page

Static project website for **DriftWAM: Faster World-Action Models via Action-Aware Video Drifting**.

- Paper: https://arxiv.org/abs/2611.33797
- Model: https://huggingface.co/wkrfugs/DriftWAM

This repository contains the website only. Figures and reported results are from the paper.

Preview locally with `python3 -m http.server 8765`, then open `http://localhost:8765`.

For GitHub Pages, select **Deploy from a branch**, branch `main`, folder `/ (root)`.
